后台通知角标：灰圆白点换成小蓝点

三处角标共用一个画法，现状是不透明灰 #343434 大圆加白点。建议改成 #0078D4 小圆点，半径缩到图标边长的六分之一（100% 缩放下直径 8px，约为图标的三分之一），去掉白点，不加环；圆心不动。蓝色是写死的常量，来自应用内标签头像的 SSH 角标；角标画在 Windows 的任务栏和托盘上，不读 ctty7 主题，也不随 Windows 浅深切换。它是图标色板之外的色相，落在粉色面板上不会粘连。三处都在右上角：窗口图标和托盘由我们画，安装版任务栏的 overlay 由 Windows 放，本机真机截图里也在右上角。

评估与建议

  1. P0同色实心的问题是颜色，不是分隔方式。圆心在粉色面板内部，#FF5FA2 的圆永远只能靠环来拆，任何环都是在给补丁描边。换成图标色板外的色相，圆点天然成立，不需要环。
  2. P1现有半径太大，尺寸按「直径约为图标的三分之一」定。现状窗口图标 0.30、overlay 0.46、托盘 0.24：24px 图标上直径 14px，占六成，overlay 更是占满 16px 槽，所以读成「一块」。建议半径 1/6 · 1/4 槽宽 · 1/6：三处在 100% 下直径 8 / 8 / 5.3px，175% 下 14 / 14 / 9px，和 Windows、macOS 的未读圆点同一量级。边界：100% 下直径不低于 5px（托盘 1/7 只有 4.6px，像素核过已成斑点），不高于图标的 40%（1/5 是 9.6px，仍可接受，再大就回到一块）。
  3. P1颜色是固定常量 #0078D4，不跟 ctty7 主题，也不跟 Windows 浅深。角标画在 Windows 的任务栏和托盘上，底色由系统主题、壁纸和透明度决定，应用主题管不到它；主题 accent 随主题漂移（Dracula 是粉，默认深色 #19AAD8 在浅色栏只有 2.3 : 1）。#0078D4 对浅/深任务栏 3.9 / 3.6 : 1，一个常量覆盖两种底；它也是标签头像上 SSH 角标写死的那个蓝（tab_strip.rs），代码里现状灰、Linux 托盘琥珀色都是常量，这次只是换值，不新增主题查询。
  4. P2蓝对粉色面板只有 1.6 : 1。靠色相差可认，8px 的点足够清楚；若真机上觉得粘，再加 1px 镂空环（上方开关可预览），实现上是 Clear 一圈 0.04 再填圆。
  5. P2安装版的位置不由我们控制。SetOverlayIcon 没有位置参数；本机底部横向任务栏实测在右上角（#212 截图），竖向任务栏曾报告在右下。三处圆心保持不变即可，不需要为位置改代码。

建议：固定色 #0078D4 小圆点，半径 1/6 · 1/4 · 1/6，无环，圆心不动

去掉灰圆和白点，三处统一为一个实心蓝点；颜色是常量，不读 ctty7 主题，也不随 Windows 浅深切换。先不加环，真机看过再定。
