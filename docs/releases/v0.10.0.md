# ctty7 v0.10.0

Manage agent panes at a glance and keep notification and reading controls clear.

## Highlights

- Name ready agent panes and split, zoom, restore, or close them from a hover toolbar (cloudy-liu/ctty7#239).
- Recognize Claude Code input requests when terminal rows include padding (cloudy-liu/ctty7#240).
- Show Windows attention with a small solid blue taskbar and tray dot, without duplicate taskbar marks (cloudy-liu/ctty7#241).

## Changes

### Added

- Show agent names with pane-specific split, zoom, restore, and close actions on ready panes (cloudy-liu/ctty7#239).

### Changed

- Keep Mermaid controls in a single toolbar above the diagram while retaining wheel, drag, and keyboard gestures (cloudy-liu/ctty7#237).
- Align sidebar leading icons and set tab titles to 13px for consistent scanning (cloudy-liu/ctty7#236).
- Draw the Windows attention mark as a small blue dot and use the system overlay alone when it is available (cloudy-liu/ctty7#241).

### Fixed

- Clear the application attention mark when any workspace window becomes active while keeping the pane result unread (cloudy-liu/ctty7#238).
- Detect Claude Code questions from padded terminal-grid rows so the sidebar shows that input is needed (cloudy-liu/ctty7#240).

## Known limitations

- Native visual acceptance for the sidebar, Mermaid controls, and agent pane chrome was performed on Windows; macOS and Linux appearance was not inspected manually.
- The Windows attention dot was inspected on a light, bottom horizontal taskbar at 175% display scale; dark and vertical taskbars remain unverified, and installed taskbar-group clearing was inconclusive.
- Installed builds use the Windows taskbar overlay for the attention mark; Alt+Tab icons do not show it.
- Claude input detection was visually checked with a deterministic Windows replay; a live Claude session and macOS/Linux screenshots were not exercised.
- Windows packages are unsigned; macOS packages use ad hoc signatures and are not notarized.
- Interactive installation and in-place upgrades of the final packages have not been verified.
