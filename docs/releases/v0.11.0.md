Select and safely trash multiple files, use Qoder and CodeBuddy agents, and tune Windows attention marks.

## Highlights

- Select file and folder ranges, then move confirmed deletions to recoverable trash on the owning local or remote host (cloudy-liu/ctty7#250).
- Recognize Qoder CLI, Qoder CN CLI, and CodeBuddy with dedicated icons, session resume/fork support, and optional hook installation (cloudy-liu/ctty7#253).
- Choose Small, Standard, or Large Windows attention dots and apply the saved size immediately (cloudy-liu/ctty7#244).

## Changes

### Added

- Select multiple Files-panel rows with Shift ranges or Ctrl/Cmd toggles, preserve selected groups on right-click, and suppress duplicate descendants when deleting folders (cloudy-liu/ctty7#250).
- Confirm recoverable deletion with a remembered opt-out, route trash to local, remote workspace/WSL, or Native SSH hosts, and preserve originals when trash is unavailable (cloudy-liu/ctty7#250).
- Recognize Qoder CLI, Qoder CN CLI, and CodeBuddy, offer resume/fork actions and opt-in hooks, and detect Qoder screen states through the pinned Herdr rules (cloudy-liu/ctty7#253).
- Adjust the Windows taskbar and tray attention dot together from notification settings; Standard is the new default and Small restores the previous size (cloudy-liu/ctty7#244).

### Changed

- Read document tabs as inset sheets with rounded top corners, a selected tab that joins the document, and short separators hidden beside the active tab (cloudy-liu/ctty7#252).

### Internal

- Keep diagnostic output and retry intermittent early exits in the Windows Ctrl+C inheritance probe so CI failures remain actionable (cloudy-liu/ctty7#250).

## Known limitations

- File selection and trash have Windows After screenshots, but a matching native Before capture was blocked; complete Before/After acceptance, dedicated Native SSH visuals, real remote/WSL restore, macOS native restore, directory-symlink behavior, Recycle Bin metadata cleanup, and trash-then-edit interactions remain unverified.
- Attention-size persistence and rendering tests passed, but durable native Before/After screenshots and taskbar/tray size comparisons remain unverified.
- Agent screenshots cover Windows Qoder idle detection and a CodeBuddy process-name stand-in; live CodeBuddy, Qoder CN CLI, live Qoder working/blocked states, and hook installation into real user configurations were not exercised.
- Downgrading after saving Qoder or CodeBuddy panes can cause older versions to quarantine machine.json and reset the workspace layout because those versions do not recognize the new agent variants.
- The new document-tab and agent visuals were inspected on Windows; macOS and Linux native appearance was not inspected manually.
- Windows packages are unsigned; macOS packages use ad hoc signatures and are not notarized.
- Interactive installation and in-place upgrades of the final packages have not been verified.
