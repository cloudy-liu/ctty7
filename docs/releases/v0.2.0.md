Markdown reading, Mermaid diagrams, clearer agent status tags, and more reliable terminal and diff workflows.

## Highlights

- Read Markdown with GitHub light/dark styling, inline Mermaid diagrams, and live custom themes (cloudy-liu/ctty7#61, cloudy-liu/ctty7#80, cloudy-liu/ctty7#88, cloudy-liu/ctty7#91).
- Find agents that need attention through compact IDLE, RUN, INPUT, and DONE sidebar tags (cloudy-liu/ctty7#100, cloudy-liu/ctty7#103).
- Keep source files readable with automatic GitHub Light or Atom One Dark colors and independent editor typography (cloudy-liu/ctty7#86, cloudy-liu/ctty7#90).
- Review changes with GitHub light/dark diff colors and content that fills the review panel (cloudy-liu/ctty7#112, cloudy-liu/ctty7#114).

## Changes

### Added

- Markdown files open in a selectable preview with links, images, tables, task lists, GitHub alerts, and a shared source/preview buffer (cloudy-liu/ctty7#61, cloudy-liu/ctty7#88, cloudy-liu/ctty7#91).
- Mermaid diagrams render inline and follow the selected Markdown palette (cloudy-liu/ctty7#80).
- Custom v2 YAML reading themes support light/dark variants, validation, live reload, and recovery when a selected theme is unavailable (cloudy-liu/ctty7#88, cloudy-liu/ctty7#102).
- Document headers expose fill/restore controls, and diff headers switch between split and unified views while keeping side panels accessible (cloudy-liu/ctty7#72).

### Changed

- Agent sidebar rows use compact uppercase status tags; the status-text setting hides tags while preserving avatar symbols (cloudy-liu/ctty7#59, cloudy-liu/ctty7#103).
- Source colors follow the application appearance, with separate source font, size, and line-height settings (cloudy-liu/ctty7#86, cloudy-liu/ctty7#90).
- File trees use Symbols icons, directory chevrons, compact rows, and collapsible roots; matching icons appear in SFTP, source control, and editor headers (cloudy-liu/ctty7#82, cloudy-liu/ctty7#83).
- Dotfiles are visible by default in the file tree (cloudy-liu/ctty7#104).
- GitHub is the only built-in Markdown reading theme; custom packages require schema v2 and an unavailable selection falls back without rewriting its saved ID (cloudy-liu/ctty7#88, cloudy-liu/ctty7#102).
- Diff content follows the application's light/dark mode with consistent context, header, gutter, and added/removed line colors (cloudy-liu/ctty7#114).

### Fixed

- Opening a cold local terminal keeps the window responsive, including retries, restored commands, and split synchronization (cloudy-liu/ctty7#92).
- Large Markdown previews reuse their measured layout when switching panels, and preview paint no longer overlaps the footer (cloudy-liu/ctty7#105).
- Filling and restoring a Markdown document preserves partial selection without freezing the window (cloudy-liu/ctty7#74).
- Terminal text remains readable after live theme changes, while disabling palette adaptation preserves literal application colors (cloudy-liu/ctty7#65, cloudy-liu/ctty7#67, cloudy-liu/ctty7#71).
- Function keys reach the terminal with modifiers, including Kitty F3 and negotiated F13-F24 support; bare F11 retains its fullscreen binding (cloudy-liu/ctty7#62, l0ng-ai/tty7#835).
- Codex's ready prompt reports idle, while unknown agent states no longer look idle or add misleading sidebar text (cloudy-liu/ctty7#58, cloudy-liu/ctty7#63, cloudy-liu/ctty7#64).
- Editor search distinguishes the current match, long footer paths truncate, and opening the command palette preserves editor focus correctly (cloudy-liu/ctty7#87, cloudy-liu/ctty7#90).
- Markdown loads relative and remote images, plays supported SVG animations, and resolves native font fallbacks for GitHub-style reading (cloudy-liu/ctty7#88, cloudy-liu/ctty7#91).
- Diff cards and rows fill the available panel width across split/unified views, focused files, resizing, and fill/restore transitions (cloudy-liu/ctty7#112).
- Cursor retains its identity through Claude-compatible hooks and the standard `agent` launcher, while delayed hooks from replaced sessions cannot overwrite the current conversation (cloudy-liu/ctty7#113).

### Internal

- Windows release-download tests wait for their HTTP fixture requests before shutting down the fixture (cloudy-liu/ctty7#66).
- Native Markdown acceptance captures cover macOS and Linux in light/dark and wide/narrow layouts (cloudy-liu/ctty7#91).
- Patch-equivalent history synchronization records the published v0.1.0 baseline and already-integrated terminal color fixes without adding behavior (cloudy-liu/ctty7#56, cloudy-liu/ctty7#65, cloudy-liu/ctty7#67, cloudy-liu/ctty7#71).

## Known limitations

- The v0.2.0 packages, their checksums, and in-place upgrades on Windows, macOS, and Linux have not yet been verified for this candidate.
- macOS packages use ad hoc signing and are not notarized.
- Native desktop acceptance for the latest diff width/palette changes and Windows Cursor startup has not been recorded.
- Real SSH/SFTP Markdown resources, near-limit document scrolling, and native macOS/Linux source-editor appearance have not been manually verified.
- Markdown supports a documented HTML subset; exact browser font rasterization, every language's token classification, and all Mermaid geometry are not guaranteed to match GitHub.
