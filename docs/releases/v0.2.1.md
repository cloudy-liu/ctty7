More faithful Skill Markdown previews and easier Mermaid diagram navigation.

## Highlights

- Read Skill metadata as a GitHub-style table, including long and multiline values, in light and dark previews (cloudy-liu/ctty7#118).
- Zoom, pan, reset, expand, and copy Mermaid diagrams directly from consistent inline and expanded-view controls (cloudy-liu/ctty7#119).

## Changes

### Added

- Valid YAML frontmatter appears as a key-value table while invalid or incomplete metadata retains its ordinary Markdown display (cloudy-liu/ctty7#118).
- Inline Mermaid diagrams expose directional movement, reset, and zoom controls alongside expand and source Copy (cloudy-liu/ctty7#119).

### Changed

- Code Copy buttons use a larger 32-pixel target and 16-pixel icon for easier clicking (cloudy-liu/ctty7#118).
- Mermaid toolbars use consistent 32-pixel controls in both inline diagrams and the expanded viewer, with space reserved around the fitted diagram (cloudy-liu/ctty7#119).

### Fixed

- Mermaid fences render with Windows CRLF line endings while source Copy preserves the original diagram text and line endings (cloudy-liu/ctty7#118).
- Metadata keys remain centered and bold, alternating row backgrounds follow the reading theme, and long values wrap inside their cells (cloudy-liu/ctty7#118).
- Each Mermaid diagram retains its own zoom and position during interaction, and Reset restores its initial fit and position (cloudy-liu/ctty7#119).

### Internal

- The pinned native text component includes metadata row-header styling and constrained table-cell wrapping (cloudy-liu/ctty7#118).

## Known limitations

- In-place upgrades from v0.2.0 on Windows, macOS, and Linux have not been manually verified.
- Native metadata-table and Mermaid-control interactions have not been manually checked on macOS or Linux.
- Real SSH/SFTP Markdown resources, near-limit document scrolling, and native macOS/Linux source-editor appearance have not been manually verified.
- Native desktop acceptance for the earlier diff width/palette changes and Windows Cursor startup has not been recorded.
