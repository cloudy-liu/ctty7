Clearer SSH and agent status indicators, with cancellable update downloads and safer failure recovery.

If update downloads fail with `UnknownIssuer`, manually install v0.2.2 once to receive the system certificate trust fix. The old installation cannot use the new downloader before upgrading (cloudy-liu/ctty7#124).

## Highlights

- Recognize SSH sessions by a small corner badge while keeping the original terminal or agent icon and its status visible (cloudy-liu/ctty7#122).
- Cancel stalled update downloads and keep recovery files when installation or process termination cannot safely finish (cloudy-liu/ctty7#125).

## Changes

### Added

- Native SSH and terminal-entered SSH sessions show an `SSH` corner badge in top tabs and sidebar rows, with the connection target available in hover details (cloudy-liu/ctty7#122).

### Changed

- Sidebar status tags use lowercase `idle`, `run`, `input`, and `done` labels with heavier text and deeper colors, while preserving space for branch names and change counts (cloudy-liu/ctty7#123).
- Release and remote-server downloads use operating system certificate verification, including configured proxies, while retaining TLS and SHA-256 verification (cloudy-liu/ctty7#124).
- Update requests, verification commands, app-exit waits, and installer helpers have cancellation or time limits; unresolved process termination retains diagnostics and prevents automatic relaunch (cloudy-liu/ctty7#125).

### Fixed

- Empty SSH tab titles fall back to the literal connection target, including IPv6 addresses, and remote identity follows the pane used for the tab title (cloudy-liu/ctty7#122).
- Settings clears obsolete download failures after their target version is installed while preserving unresolved download, installation, and recovery errors (cloudy-liu/ctty7#124).
- Failed macOS or AppImage replacement preserves the previous copy when restoration fails, and a successful restoration reports the original error before relaunching (cloudy-liu/ctty7#125).
- Cancellation stops pending TLS, response, checksum, and package waits; required-proxy failures do not fall back to direct downloads, and redirects respect proxy bypass rules (cloudy-liu/ctty7#125).
- Recovery stages survive immediate cleanup and later orphan sweeps; ordinary Windows stages retry cleanup after the staged updater exits (cloudy-liu/ctty7#125).

### Internal

- Native SSH badge capture fixtures and update regression suites cover pane identity, stalled requests, process deadlines, recovery preservation, and elevated Windows access-denied behavior (cloudy-liu/ctty7#122, cloudy-liu/ctty7#125).

## Known limitations

- The certificate environment of the affected computer has not been reproduced or verified after upgrading.
- Real Setup/UAC upgrades and in-place upgrades from v0.2.1 on Windows, macOS, and Linux have not been manually verified. Windows Setup has no complete application-owned rollback, so a stopped installer may require manual repair.
- Live remote-agent detection and native macOS SSH badge appearance have not been manually verified; the recorded badge captures use deterministic fixtures on Windows and Linux.
- Native macOS/Linux sidebar status appearance, metadata-table and Mermaid-control interactions, real SSH/SFTP Markdown resources, near-limit document scrolling, and source-editor appearance have not been manually verified.
- Native desktop acceptance for the earlier diff width/palette changes and Windows Cursor startup remains unrecorded. macOS packages use ad hoc signing and are not notarized.
