Agent completion and input alerts across desktop platforms, with more reliable paste, status detection, and diagram navigation.

Linux source builds now require `libpulse-dev`; audible alerts require a PulseAudio-compatible service, including PipeWire's PulseAudio service (cloudy-liu/ctty7#138).

## Highlights

- Hear when an agent finishes or needs input on Windows, macOS, and Linux, with independent sound and desktop notification controls (cloudy-liu/ctty7#138).
- Keep Cursor identity stable, paste into coding agents with Ctrl+V, and copy file or folder names from the file tree (cloudy-liu/ctty7#129, cloudy-liu/ctty7#128, cloudy-liu/ctty7#130).

## Changes

### Added

- Agent alerts include the built-in Codex Default sound, a Preview action, and Never, When unfocused, and Always policies on Windows, macOS, and Linux (cloudy-liu/ctty7#138).
- File-tree context menus offer Copy Name for files and folders without copying their paths (cloudy-liu/ctty7#130).

### Changed

- Desktop notifications and sounds have separate policies, use whole-application focus, and follow the same agent lifecycle events from hooks and screen detection (cloudy-liu/ctty7#138).

### Fixed

- Ctrl+V pastes into coding agents while preserving their external-editor shortcuts (cloudy-liu/ctty7#128).
- Cursor tabs retain their identity when anonymous legacy hooks or BOM-prefixed hook data arrive (cloudy-liu/ctty7#129).
- Codex draft input stays idle while Working and Blocked signals retain their status priority (cloudy-liu/ctty7#131).
- Expanded Mermaid diagrams pan across their full rendered bounds and support wheel scrolling (cloudy-liu/ctty7#131).
- Daemon shutdown waits for released locks before clearing PID records and preserves a successor daemon's records (cloudy-liu/ctty7#132).
- Repeated lifecycle events and restored sessions avoid duplicate alerts or replaying old completions, and overlapping sound requests do not queue (cloudy-liu/ctty7#138).

### Internal

- Linux builds install the PulseAudio development dependency, and notification regression coverage checks lifecycle transitions, focus changes, and independent channel policies (cloudy-liu/ctty7#138).

## Known limitations

- Audible notification acceptance remains unverified on Windows, macOS, and native Linux desktops; Windows preview checks ran with the system output muted.
- Live desktop notification delivery, click behavior, and system-disabled banner behavior have not been manually verified across all three platforms.
- Real Setup/UAC upgrades and in-place upgrades from v0.2.2 on Windows, macOS, and Linux have not been manually verified.
- Native macOS/Linux acceptance for Copy Name, agent paste and status behavior, and expanded Mermaid interactions has not been manually verified.
- Real SSH/SFTP Markdown resources, near-limit document scrolling, native macOS/Linux source-editor appearance, and the earlier diff width/palette changes have not received complete manual desktop acceptance.
- macOS Gatekeeper acceptance has not been verified; the packages use ad hoc signing and are not notarized.
