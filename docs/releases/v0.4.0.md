# ctty7 v0.4.0

Keep background agent work visible with clearer status and remote-session cues.

## Highlights

- Get independent sound and desktop alerts when an agent needs input or finishes (cloudy-liu/ctty7#138).
- Recognize active work and SSH sessions through animated status marks and a blue Remote badge (cloudy-liu/ctty7#143, cloudy-liu/ctty7#144).

## Changes

### Added

- Play agent alert sounds and set desktop notification policies independently on Windows, macOS, and Linux (cloudy-liu/ctty7#138).

### Changed

- Animate working status marks in tabs and the sidebar with one shared low-frequency clock per window (cloudy-liu/ctty7#143).
- Mark SSH sessions with the VS Code Remote glyph in tabs and sidebar rows (cloudy-liu/ctty7#144).
- Refresh English and Chinese README feature descriptions and native screenshots (cloudy-liu/ctty7#145).

### Fixed

- Suppress repeated agent alerts and avoid replaying restored events or queueing overlapping sounds (cloudy-liu/ctty7#138).

### Internal

- Align workspace and lockfile package versions with this release (cloudy-liu/ctty7#146).

## Known limitations

- Actual sound output and live desktop-notification delivery and click behavior have not been manually verified on all three platforms.
- Native macOS and Linux appearance of the animated status marks and Remote badge has not been manually checked.
- Release-build CPU, GPU, and energy use for the animation have not been measured; the animation does not follow a system reduced-motion preference.
- Setup and in-place upgrades from v0.3.0 have not been manually verified, and macOS packages are ad hoc signed and not notarized.
