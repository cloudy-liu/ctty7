# ctty7 v0.5.0

Read long diffs and Mermaid diagrams more easily, with more accurate agent status inside Herdr.

## Highlights

- Select and copy diff text, and scroll horizontally to read long lines (cloudy-liu/ctty7#147, cloudy-liu/ctty7#150).
- Open tall Mermaid diagrams at a readable size and navigate long Markdown previews with less rendering work (cloudy-liu/ctty7#148).
- Keep agent activity and approval states visible, including Cursor running inside Herdr (cloudy-liu/ctty7#149, cloudy-liu/ctty7#152).

## Changes

### Added

- Select individual characters and copy selected text in diff views (cloudy-liu/ctty7#150).

### Changed

- Read expanded Mermaid diagrams at natural width with scrollbars, wheel navigation, zoom, and reset controls (cloudy-liu/ctty7#148).
- Scroll long Markdown previews with fewer offscreen layout and paint operations (cloudy-liu/ctty7#148).

### Fixed

- Reach the ends of long lines by scrolling horizontally in split and unified diff views (cloudy-liu/ctty7#147).
- Recognize updated AGY, Pi, Grok, and Codex activity and preserve streamed progress across reconnects (cloudy-liu/ctty7#149).
- Show Cursor working and approval states when Herdr's pane divider precedes its status text (cloudy-liu/ctty7#152).
- Preserve Shift+Enter through native Windows Herdr when it negotiates Win32 input mode (cloudy-liu/ctty7#151).

## Known limitations

- Live Herdr end-to-end checks for nested Cursor status, all split layouts, and Shift+Enter remain incomplete.
- Final manual Mermaid source-editing, compact-window, and wide/sequence interaction rechecks remain incomplete; native macOS and Linux interaction has not been manually verified.
- Setup and in-place upgrades from v0.4.0 have not been manually verified, and macOS Gatekeeper acceptance has not been manually checked.
