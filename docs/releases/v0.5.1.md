# ctty7 v0.5.1

Organize projects with pinned, collapsible sidebar groups and review changes with faster diffs and full-file context.

## Highlights

- Pin local project groups, fold inactive groups, and reopen terminals from empty pinned projects (cloudy-liu/ctty7#161).
- Review highlighted changes alongside the complete file and jump between changes in split or unified diffs (cloudy-liu/ctty7#158).
- Scroll large diffs with less rendering work and read wrapped Markdown tables with accurate text selection (cloudy-liu/ctty7#154, cloudy-liu/ctty7#155, cloudy-liu/ctty7#159).

## Changes

### Added

- Keep local projects at the top of the sidebar with saved pin order, drag reordering, persistent folds, fold-all controls, and a New Tab Here action (cloudy-liu/ctty7#161).
- Search tabs inside folded groups without changing saved folds, and keep tab shortcut positions consistent with sidebar group order (cloudy-liu/ctty7#161).
- Switch between changed regions and full-file context, reveal surrounding lines, and navigate to the previous or next change (cloudy-liu/ctty7#158).

### Changed

- Open and scroll large diffs with only visible rows laid out while preserving offscreen selections and horizontal offsets (cloudy-liu/ctty7#154).
- Read Markdown tables with adaptive wrapping, responsive reader padding, and a consistent panel-edge scrollbar (cloudy-liu/ctty7#155).
- Identify open files through project-relative breadcrumbs, a filename-adjacent icon, and compact header actions (cloudy-liu/ctty7#156).

### Fixed

- Select and copy the visible text in centered and right-aligned Markdown table cells, including reverse drags (cloudy-liu/ctty7#159).
- Keep SSH connection names and remote directories associated with the correct pane in tabs, the sidebar, and the workspace switcher (cloudy-liu/ctty7#157).

### Internal

- Preserve existing UI and Markdown fixes with an exact gpui-component revision from the fork's stable ctty7 integration branch (cloudy-liu/ctty7#160).
- Run the notification-settings persistence check in its own test process to avoid shared configuration races (cloudy-liu/ctty7#159).

## Known limitations

- Sidebar pins apply to local projects; remote pinning and keyboard navigation of group headers are not supported.
- Full-file diff context retains at most 50,000 lines; loading failures leave the original patch available.
- Native macOS and Linux interaction, live SSH behavior, setup and in-place upgrades from v0.5.0, and macOS Gatekeeper acceptance have not been manually verified for this release.
