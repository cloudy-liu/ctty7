# ctty7 v0.7.0

Preview local HTML on Windows, keep track of unread Agent results, and navigate projects with more reliable sidebar groups and document paths.

Upgrade note: Windows HTML preview requires Microsoft Edge WebView2 Runtime. Install it if it is unavailable on your system before using the preview.

## Highlights

- Preview saved local HTML files with their CSS, JavaScript and relative resources inside the Windows document panel (cloudy-liu/ctty7#172).
- Notice unread background Agent results through matching Windows taskbar and tray indicators, and clear them by viewing the result (cloudy-liu/ctty7#173).
- Keep project tabs in their sidebar groups and read document breadcrumbs starting at the project root (cloudy-liu/ctty7#171, cloudy-liu/ctty7#174).

## Changes

### Added

- Switch saved local Windows HTML and HTM files from source editing to an embedded WebView2 preview, refresh the page, or open it in the external browser (cloudy-liu/ctty7#172).
- Keep a Windows taskbar and tray reminder for unread Agent completions, including a selected pane in an inactive window, until the result is viewed (cloudy-liu/ctty7#173).

### Changed

- Open folders from Explorer or the command line with their sidebar group expanded, visible and scrolled into view, including after a delayed repository probe (cloudy-liu/ctty7#170).
- Read sidebar group headers at 13px while preserving the existing tab-title and metadata sizes (cloudy-liu/ctty7#169).
- Read Markdown and source breadcrumbs from the project root, with adjacent filename labels and normalized Windows path display (cloudy-liu/ctty7#174).

### Fixed

- Keep Escape responsive in Codex after Shift+Enter by sending complete Win32 key events when that input mode is active (cloudy-liu/ctty7#166).
- Keep tabs in their existing sidebar group when a Git or host probe fails, and retry unanswered probes after ten seconds (cloudy-liu/ctty7#171).
- Recognize Claude forms above named-session footers as waiting for input, including wrapped controls and an optional counted task panel (cloudy-liu/ctty7#165).

### Internal

- Display embedded WebView2 content alongside transparent Windows rendering through an immutable GPUI dependency revision (cloudy-liu/ctty7#172).

## Known limitations

- Behavior on a Windows machine without WebView2 Runtime has not been verified.
- Sustained terminal output during HTML preview, the full Mica/Acrylic matrix, and multi-monitor DPI transitions have not been benchmarked.
- Windows attention-indicator recovery after an Explorer restart has not been manually verified.
- Native acceptance of the added Claude named-session form rule has not been performed.
- Setup, in-place upgrades from v0.6.0, native macOS and Linux interaction with the final packages, and macOS Gatekeeper acceptance have not been manually verified.
