# ctty7 v0.7.1

Open local HTML directly in Windows preview and keep terminal input fills continuous across theme changes.

## Highlights

- Open saved local Windows HTML and HTM files directly in the embedded browser preview (cloudy-liu/ctty7#176).
- Keep explicitly colored block characters aligned with terminal input backgrounds when switching themes (cloudy-liu/ctty7#176).

## Changes

### Fixed

- Read newly opened local HTML pages immediately by restoring default preview and creating the browser on the first render (cloudy-liu/ctty7#176).
- Recover usable source editing when automatic HTML preview initialization fails, while preserving explicit source navigation and unsaved changes (cloudy-liu/ctty7#176).
- Remove bright half-block edges around terminal input fills by mapping explicitly colored block characters with the background palette (cloudy-liu/ctty7#176).

### Internal

- Include preserved local fixes in release preparation through a recorded audit of temporary patches, stashes, and squash-merged history (cloudy-liu/ctty7#176).

## Known limitations

- Windows installation and in-place upgrades, recovery on a machine without WebView2 Runtime, and native macOS/Linux interaction with the final packages have not been manually verified.
- Sustained terminal output during HTML preview, the full Mica/Acrylic matrix, and multi-monitor DPI transitions have not been benchmarked.
