# ctty7 v0.8.0

Keep multiple files open in document tabs, preview local HTML on macOS, and retain your place while reviewing files and diffs.

## Highlights

- Keep multiple documents open with independent file tabs, breadcrumbs, and explicit preview/source controls (cloudy-liu/ctty7#186).
- Preview saved local HTML directly on macOS using the system browser engine (cloudy-liu/ctty7#178).
- Keep each HTML document's reading position when switching files, source mode, or terminal sessions (cloudy-liu/ctty7#191).

## Changes

### Added

- Open and close multiple files within each terminal session while preserving each document's edits and selected mode (cloudy-liu/ctty7#186).
- Open local HTML from the file context menu and use native preview on macOS (cloudy-liu/ctty7#179, cloudy-liu/ctty7#178).

### Changed

- Read expanded diff context directly inside the file list without opening a separate overlay (cloudy-liu/ctty7#187).
- Keep document tabs, source backgrounds, and gutters aligned with the selected application theme while retaining syntax colors (cloudy-liu/ctty7#186).

### Fixed

- Retain independent HTML scroll positions across file and session switches, browser recreation, and source/preview transitions (cloudy-liu/ctty7#191).
- Show files created during asynchronous watch registration without reopening the directory (cloudy-liu/ctty7#190).
- Attribute Codex hooks to their owning pane and leave ambiguous hooks unassigned (cloudy-liu/ctty7#180).
- Distinguish Markdown code-block backgrounds in the One Light theme (cloudy-liu/ctty7#181).
- Clear unread results when returning to a window and restore pane focus after marking a result unread (cloudy-liu/ctty7#177).
- Keep taskbar attention marks in the upper-right corner (cloudy-liu/ctty7#189).

## Known limitations

- Windows installation and in-place upgrades, recovery without WebView2 Runtime, and manual interaction with the final macOS/Linux packages have not been verified.
- Sustained terminal output during HTML preview, the full Mica/Acrylic matrix, and multi-monitor DPI transitions have not been benchmarked.
