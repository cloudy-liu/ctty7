# ctty7 v0.8.1

Read Mermaid diagrams more comfortably, keep document headers compact, and get clearer Windows attention indicators.

## Highlights

- Read tall Mermaid diagrams at their natural proportions and zoom expanded diagrams around the pointer with the mouse wheel (cloudy-liu/ctty7#197).
- Keep file tabs compact and align breadcrumbs with the Files panel header (cloudy-liu/ctty7#201).
- Notice larger Windows attention badges and recover the normal application icon after clearing unread results (cloudy-liu/ctty7#196, cloudy-liu/ctty7#194).

## Changes

### Changed

- Navigate expanded Mermaid diagrams with ordinary wheel zoom, left-button panning, Fit whole diagram, and reset controls (cloudy-liu/ctty7#197).
- Read denser file tabs and aligned document headers with labels that follow the UI font scale (cloudy-liu/ctty7#201).
- Recognize Command Palette and Settings more quickly through search and gear icons in the application menu (cloudy-liu/ctty7#200).

### Fixed

- Keep tall inline Mermaid diagrams fully accessible without shrinking them into a capped canvas or intercepting normal document scrolling (cloudy-liu/ctty7#197).
- Keep long English, CJK, mixed-language, and explicit-line-break Mermaid labels within node bounds (cloudy-liu/ctty7#197).
- Keep Mermaid rasters matched to display DPI and zoom within bounded image allocations (cloudy-liu/ctty7#197).
- Restore the normal Windows taskbar icon when attention clears, including windows that use a shared class icon (cloudy-liu/ctty7#194).
- Show larger unread badges in the upper-right corner of Windows taskbar and tray icons (cloudy-liu/ctty7#196).
- Keep HTML preview active and retain its reading position after fragment navigation and document switching (cloudy-liu/ctty7#193).

### Internal

- Review workspace, document, and HTML workflows through refreshed native documentation captures with recorded baseline provenance (cloudy-liu/ctty7#202).

## Known limitations

- Final Windows Mermaid screenshots, manual short/long-diagram interaction, and real multi-monitor DPI switching remain unverified; the recorded screenshot-capture limitation was accepted for this release.
- Interactive visual acceptance of the hidden Windows notification-tray badge remains unverified; the recorded limitation was accepted for this release.
- Compact headers were visually inspected on Windows; macOS/Linux header appearance and Windows/macOS menu-icon appearance were not inspected locally.
- Windows installation and in-place upgrades, recovery without WebView2 Runtime, and manual interaction with the final macOS/Linux packages have not been verified.
- Sustained terminal output during HTML preview and the full Mica/Acrylic matrix have not been benchmarked.
