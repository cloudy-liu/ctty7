# ctty7 v0.8.2

Reach commands and settings directly from the titlebar and use clearer, lighter document preview controls.

## Highlights

- Open Command Palette and Settings in one click from dedicated titlebar buttons (cloudy-liu/ctty7#205).
- Keep Markdown and HTML preview controls compact with transparent resting icons (cloudy-liu/ctty7#204, cloudy-liu/ctty7#205).
- Read Windows HTML preview tooltips without the browser covering their lower edge (cloudy-liu/ctty7#204).

## Changes

### Changed

- Reach command search and settings directly from the titlebar instead of opening the overflow menu first (cloudy-liu/ctty7#205).
- Save document-header space with a single preview toggle and project-relative breadcrumbs (cloudy-liu/ctty7#204).
- Distinguish source and preview modes through eye-off and eye icons with a transparent resting background (cloudy-liu/ctty7#205).

### Fixed

- Keep tooltips visible where they overlap Windows HTML previews and restore the browser's full region after dismissal (cloudy-liu/ctty7#204).

## Known limitations

- Native macOS/Linux and dark-theme visual acceptance of the titlebar and preview controls remains unverified.
- Matched native before/after screenshot acceptance of the active Windows HTML tooltip remains unverified.
- Interactive installation and in-place upgrades of the final packages, recovery without WebView2 Runtime, and sustained terminal-output performance during HTML preview have not been verified.
