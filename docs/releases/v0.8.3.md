# ctty7 v0.8.3

Browse Git history with author photos and complete commit documents, and use clearer source and diff controls.

## Highlights

- Open any History commit in its own document tab with the full message, author, date, copyable SHA and file changes (cloudy-liu/ctty7#209).
- Recognize contributors through cached author photos and compact two-line History rows (cloudy-liu/ctty7#209).
- Reach long source lines immediately through visible overflow scrollbars (cloudy-liu/ctty7#210).

## Changes

### Added

- Browse History with optional remote author photos, shared bounded caches and offline initials or cached-photo fallback (cloudy-liu/ctty7#209).
- Read selected commits in an independent document tab alongside open files, with expandable complete messages and the existing Diff controls (cloudy-liu/ctty7#209).
- Dismiss unsupported file-preview hints permanently from the hint or restore them in notification settings (cloudy-liu/ctty7#211).

### Changed

- Reveal hidden Diff context with GitHub-style directional controls and a single combined control for short gaps (cloudy-liu/ctty7#206).

### Fixed

- Reach the end of overflowing source lines using scrollbars that are available as soon as the document opens (cloudy-liu/ctty7#210).
- Keep Diff hunk backgrounds filled across each column, including after horizontal scrolling (cloudy-liu/ctty7#206).
- Keep the current document visible when an archive or binary file cannot be previewed, while retaining read and text-encoding errors (cloudy-liu/ctty7#211).

## Known limitations

- Native visual acceptance of the History, source scrollbar, Diff controls and unsupported-preview changes covers Windows; their macOS/Linux appearance has not been inspected manually.
- History measurements cover CPU scrolling work and whole-process memory on one Windows machine; GPU frame pacing, network latency and isolated avatar allocation have not been measured.
- Author photos do not guarantee matching arbitrary Git email addresses to GitHub accounts; unavailable photos fall back to local initials.
- Interactive installation and in-place upgrades of the final packages have not been verified.
