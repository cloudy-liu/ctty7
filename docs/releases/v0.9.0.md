# ctty7 v0.9.0

Review remote Git changes directly in native SSH tabs and reconnect to the same saved agent conversations.

**Upgrade note:** If an older background server remains running after the update, restart it from Settings and reconnect your SSH tabs to enable Native SSH Git (cloudy-liu/ctty7#224).

## Highlights

- See the remote branch and change counts in native SSH tabs, then click the counts to review the owning remote repository's diff (cloudy-liu/ctty7#224).
- Reopen saved SSH connections and resume known Claude Code or Codex conversations with their exact session IDs, launch flags, and remote directories (cloudy-liu/ctty7#217).
- Give commit messages and diffs the space they need with a draggable divider and compact document-strip actions (cloudy-liu/ctty7#218).
- Recognize working agents through a turning comet with a fading tail in both light and dark themes (cloudy-liu/ctty7#219).

## Changes

### Added

- Inspect read-only Git status, tracked changes, untracked files, and full-context diffs through the native SSH pane's existing connection (cloudy-liu/ctty7#224).

### Changed

- Keep remote Git views current after external edits, tab changes, disconnects, and reconnects while preserving each pane's repository identity (cloudy-liu/ctty7#224).
- Keep commit diff actions in the document tab strip, center author initials, and resize the message and diff regions independently (cloudy-liu/ctty7#218).
- Distinguish working agents with an open comet shape and smoother rotation while hidden badges remain idle (cloudy-liu/ctty7#219).

### Fixed

- Keep Diff reading surfaces aligned with the application theme while preserving GitHub addition, deletion, and hunk colors (cloudy-liu/ctty7#225).

- Reattach live SSH panes without launching a duplicate agent and redial missing panes over SSH after application or daemon restarts (cloudy-liu/ctty7#217).
- Resume saved remote conversations once the remote shell prompt is ready, honoring restoration settings, session-history opt-outs, and user-input cancellation (cloudy-liu/ctty7#217).

### Internal

- Keep Apple Silicon source checks on macOS 15 runners (cloudy-liu/ctty7#216).

## Known limitations

- Native SSH Git requires a POSIX remote shell, confirmed remote working-directory integration, and Git support for `--path-format=absolute`; nested SSH commands entered manually are outside this feature.
- Native SSH Git and commit-layout visual acceptance covers Windows; their macOS/Linux appearance has not been inspected manually.
- Real Claude Code/Codex service histories and remote hooks were not exercised; restoration was verified with a deterministic SSH/agent fixture and requires a supported remote shell plus a known exact session ID.
- Commit divider positions are retained for the open document rather than across application restarts; comet animation repaint cost has not been profiled.
- Interactive installation and in-place upgrades of the final packages have not been verified.
