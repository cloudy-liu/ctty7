# ctty7 v0.9.0

Review remote Git changes in native SSH tabs, restore saved agent conversations, and organize SSH sessions in the sidebar.

**Upgrade note:** If an older background server remains running after the update, restart it from Settings and reconnect your SSH tabs to enable Native SSH Git (cloudy-liu/ctty7#224).

## Highlights

- See remote branches and change counts in native SSH tabs and open the owning repository's diff (cloudy-liu/ctty7#224).
- Reopen saved SSH connections and resume supported Claude Code or Codex conversations with their saved session IDs and launch settings (cloudy-liu/ctty7#217).
- Find in-pane SSH sessions under their own host groups instead of Scratch (cloudy-liu/ctty7#230).
- Choose sidebar group arrows and project folder icons independently (cloudy-liu/ctty7#227).
- Resize commit messages and diffs independently, with compact document-strip actions (cloudy-liu/ctty7#218).

## Changes

### Added

- Inspect read-only Git status, tracked changes, untracked files, and full-context diffs through a native SSH connection (cloudy-liu/ctty7#224).
- Recognize Scratch at a glance through its Inbox icon (cloudy-liu/ctty7#233).

### Changed

- Keep remote Git views current after external edits, tab changes, disconnects, and reconnects (cloudy-liu/ctty7#224).
- Group in-pane SSH sessions by their displayed host and allow each group to be folded or renamed (cloudy-liu/ctty7#230).
- Indent sessions beneath sidebar group headings while retaining full-width row targets (cloudy-liu/ctty7#229).
- Keep commit diff actions in the document tab strip, center author initials, and resize the message and diff regions independently (cloudy-liu/ctty7#218).
- Distinguish working agents with a turning comet and fading tail (cloudy-liu/ctty7#219).

### Fixed

- Close an unedited document preview normally after its file or parent folder is deleted, while preserving unsaved-edit protection (cloudy-liu/ctty7#228).
- Keep Diff reading surfaces aligned with the application theme while preserving addition, deletion, and hunk colors (cloudy-liu/ctty7#225).
- Reattach live SSH panes without launching duplicate agents and redial missing panes after application or daemon restarts (cloudy-liu/ctty7#217).
- Resume saved remote conversations when the shell prompt is ready, respecting restoration settings and user input (cloudy-liu/ctty7#217).

### Internal

- Keep Apple Silicon source checks on macOS 15 runners (cloudy-liu/ctty7#216).

## Known limitations

- Native SSH Git requires a POSIX remote shell, working-directory integration, and Git support for `--path-format=absolute`; nested SSH commands entered manually are outside this feature.
- SSH sidebar groups use the displayed connection target; matching aliases can share a group, and an unparseable hop may remain outside a host group.
- Windows visual acceptance uses a deterministic SSH fixture; live SSH grouping and macOS/Linux appearance were not inspected manually.
- Real Claude Code/Codex service histories and remote hooks were not exercised; restoration was verified with a deterministic fixture and requires a known exact session ID.
- Commit divider positions last for the open document rather than across restarts; comet animation repaint cost has not been profiled.
- Windows packages are unsigned; macOS packages use ad hoc signatures and are not notarized.
- Interactive installation and in-place upgrades of the final packages have not been verified.
